# Ouest

SwiftUI iOS app for collaborative group travel (Supabase backend, `supabase/`),
plus a small landing/link-preview site in `web/`. Architecture: `docs/ARCHITECTURE.md`.

## Design

- Read `DESIGN.md` before any UI work. It is the spec for tokens, components and motion.
- Building or restyling SwiftUI: use the `ios-design` skill.
- Reviewing or polishing an existing screen: use the `design-critique` skill.
- External design skills we evaluated and how to install them: `docs/DESIGN_SKILLS.md`.

## Commands

- `/verify` runs build, tests and security checks. Run it before committing Swift changes.
- `/commit` commits and pushes.
